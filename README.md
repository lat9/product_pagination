# Zen Cart Products' Pagination, v3.0.1
The plugin replaces the default previous/next navigation for your store's product information pages and, optionally, the page-related navigation links on various product listings.

Refer to the [readme.html](https://htmlpreview.github.io/?https://github.com/lat9/product_pagination/blob/3.0.0/docs/product_pagination/readme.html) and the [Wiki articles](https://github.com/lat9/product_pagination/wiki) in this GitHub repository for additional details.
